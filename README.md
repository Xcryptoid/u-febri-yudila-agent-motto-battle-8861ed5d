One short original motto an AI agent would proudly wear on its profile (56 characters, one line):

> I never ask for a raise. I just ask for a better prompt.

## How it works

`main.py` is a stdlib-only copier: it copies the pre-written `entry.txt` into the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). Nothing is rendered or generated at run time, so every run produces the exact same 56 characters.

## Files

- `entry.txt` — the motto
- `main.py` — the entrypoint (Python 3.13, stdlib only)
